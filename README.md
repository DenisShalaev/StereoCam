# StereoCam — стереофото двумя камерами телефона одновременно

Отдельный проект на основе кода StereoPano (запись `.vr.jpg`, стиль интерфейса, 7 языков).
**Статус: build 2, ни разу не запускался на телефоне.** Android-код здесь не компилировался (нет Android SDK);
проверены только чистые Java-части на настольной JVM (см. «Что проверено»).

Полная документация со списком телефонов: [русский](docs/README.ru.md) · [English](docs/README.en.md) · [Deutsch](docs/README.de.md).

## Как это работает
1. **Проверка камер** (стартовый экран). Находит логические мультикамеры (Camera2, Android 9+) и их физические камеры,
   показывает фокусные расстояния (кадр 35 мм), базу между линзами (из `LENS_POSE_TRANSLATION`), минимальную дистанцию фокуса,
   тип синхронизации сенсоров. Отчёт можно отправить («Отправить отчёт») — по нему видно, отдаёт ли телефон камеры приложениям.
2. **Съёмка.** Одна сессия Camera2: превью + два JPEG-потока, каждый привязан к своей физической камере
   (`OutputConfiguration.setPhysicalCameraId`). Один запрос → два снимка. Если телефон не принимает полное разрешение,
   приложение пробует 3264 и 2048 пикселей по длинной стороне.
3. **Обработка** (`Processor`, `StereoAligner`):
   - поворот кадров по `SENSOR_ORIENTATION` и повороту экрана;
   - выравнивание угла обзора: у более широкой камеры берётся центр, чтобы совпасть с узкой (по эквивалентным фокусным);
   - сопоставление блоков (NCC) → робастная подгонка: вертикальный сдвиг, поворот, разница масштаба;
   - конвергенция (плоскость нулевой диспаритетности — медиана по кадру), общая обрезка краёв;
   - какой кадр левый — по положению линз (`LENS_POSE_TRANSLATION`) и повороту экрана; кнопка «Л/П» меняет вручную.
4. **Файлы** в `Pictures/StereoCam`: MPO (стандарт 3D-фото), JPEG side-by-side, `.vr.jpg` (для StereoPano Viewer), анаглиф, отдельные L/R.

## Сборка
Открыть папку в Android Studio (Hedgehog или новее), дождаться синхронизации Gradle (если Studio предложит создать
Gradle wrapper — согласиться), Run. minSdk 28.

## Что проверено (на настольной JVM, `test/AlignTest.java`)
- Выравнивание на синтетической паре со сдвигом 7 пикселей, поворотом 0,5°, масштабом 1,2 % и «вынесенным вперёд» объектом:
  параметры восстанавливаются (a≈7,3, b≈0,0089 при истинном 0,0087, c=0,0120 при истинном 0,0120); после коррекции остаток ≈ 0.
- MPO: индекс MPF читается обратно, размеры и смещения сходятся, оба JPEG декодируются.

## Что НЕ проверено
- Всё, что работает с Android: камеры, сессия с двумя физическими потоками, превью и его поворот, сохранение через MediaStore.
- Многие телефоны не отдают сторонним приложениям две физические камеры одновременно, а MPO через MediaStore может сохраниться
  не в «Pictures», а в «Download» (приложение сначала пробует Pictures с типом image/mpo, потом Download).
- Реальные снимки: синтетический тест не заменяет настоящие сцены (блики, повтор текстуры, мало деталей).
- Базы фиксированной камеры (1–2 см) для макро слишком велики: для объекта ближе ~30 см диспаритетность будет большой.
  Для макро нужен режим поворотного столика или съёмки двумя кадрами — в этом проекте он ещё не реализован.
- Перевод строк не вычитывался носителями языков.

## Структура
`ProbeActivity` (проверка и настройки) · `DualCaptureActivity` (съёмка) · `DualProbe` (поиск пар) · `Processor` (обработка и запись) ·
`StereoAligner` (чистая Java: оценка и коррекция) · `MpoWriter` · `VrJpgWriter`, `ExifGps` (из StereoPano) · `Prefs` · `Ui` ·
`tools/gen_strings.py` (строки 7 языков → `res/values*/strings.xml`).
